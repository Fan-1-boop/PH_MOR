# Dataset and artifact manifest

The original research-session archives contained code, generated JSON data and figures. The **GitHub repository currently commits the complete set of Python source scripts for Phases 1 and 2**, both phase-specific READMEs, both Chinese technical reports, and the Phase 2 numerical `results.json`.

## Recompute Phase 1 outputs

Phase 1 result files are generated by the scripts and were not included as committed binaries/data in the initial repository import:

- `results.json` — `experiment.py`
- `stress_results.json` — `stress.py`
- `rankone_results.json` — `rankone.py`
- `intrinsic_result.json` — `intrinsic.py`
- `margin_results.json` — `margin.py`
- `tradeoffs.json` — `tradeoffs.py`
- `audits.json`, `hankel_ratio_methods.png`, `p_effect.png`, `homotopy_time.png` — `audit.py`

Phase 2 `reproduce.py` regenerates `results.json`, `certified_gap.png`, `ritz_certificates.png`, and `perturbation_robustness.png`.

To regenerate all artifacts:

```bash
python -m pip install -r requirements.txt
bash scripts/reproduce_all.sh
```

This script can take several minutes depending on the machine. Outputs may vary slightly due to numerical libraries and optimization timings. The previous conversation's original ZIP packages additionally preserve archived historical outputs outside this GitHub repository.

## Validation at import time

- All source scripts from the two original archives passed Python syntax compilation.
- Phase 1 core functions passed a small Schatten objective/gradient and stable-ROM smoke test.
- Phase 2 `reproduce.py` reran successfully, including the reported 4-to-1 Hankel gap (`4.9266273` versus `5.0699427`) in double precision.

These checks are computational reproducibility checks, **not independent novelty review or formal exact-arithmetic proof verification**.
